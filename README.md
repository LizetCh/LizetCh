# Hi, I'm Liz 👋
 
AI Engineer in progress — Backend Development & LLM Integration
 
I'm an Information Technology and Digital Business Engineering student (graduating Dec 2026) building backend systems with Python and integrating Large Language Models into real, working products. I care about structured, reliable AI outputs — not just prompts that "kind of work."
 
## 🔭 What I'm building
 
**[GoalBreaker](https://github.com/LizetCh/goalbreaker)** — A Generative AI task automation API. Takes a user's goal as input and returns structured Agile tasks (Epics, User Stories, Subtasks) using the Gemini API.
- Strict input/output validation with Pydantic schemas
- Retry logic with exponential backoff for API reliability
- Deployed in production on Render, with public Swagger docs
- 🔗 [Live demo](https://goalbreaker-vfb9.onrender.com/docs#/) · [Code](https://github.com/LizetCh/goalbreaker)

**DataStrat** — Co-founder & Chief Engineer. A WhatsApp-based inventory and sales tool for microenterprises, currently in testing with real pilot users.
- FastAPI backend, PostgreSQL via Supabase
- WhatsApp integration (EvolutionAPI) deployed on AWS EC2
- Multi-service architecture containerized with Docker Compose
- Agile development: sprints, story points, Jira
